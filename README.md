# Adventure Escape SA

## Digital Booking Platform

Adventure Escape SA is an outdoor adventure and eco-tourism business based in the Western Cape, South Africa. This project proposes a responsive digital platform that allows customers to explore adventure experiences, view activities, and submit booking requests through a professional and user-friendly interface.

The project was developed as part of the **Work Integrated Learning 1 (XHAW5112)** project.

---

## Project Overview

Adventure Escape SA currently requires a centralised digital platform where customers can easily discover, compare, and book its outdoor experiences.

The proposed solution consists of:

* A responsive website
* An Android mobile application
* Adventure package browsing
* Individual activity browsing
* Booking functionality
* Clear and user-friendly navigation
* Professional branding and visual design

The goal is to create a convenient digital experience for customers while providing Adventure Escape SA with a more organised way to present and manage its offerings.

---

## Main Features

### Adventure Packages

Customers can browse available adventure packages and view information about each experience.

**Package price:** R1,500 per package.

### Individual Activities

Customers can also select individual activities rather than booking a complete package.

**Activity price:** R750 per activity.

### Booking

The platform allows customers to submit booking requests for their selected adventure experiences.

### Responsive Design

The website is designed to provide a consistent experience across different screen sizes, including:

* Desktop
* Tablet
* Mobile

### User-Centred Design

The application focuses on:

* Simple navigation
* Clear information
* Accessibility
* Ease of use
* Consistent visual design
* Efficient booking processes
